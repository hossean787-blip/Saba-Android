## ساختار و راه‌اندازی

- رابط کاربری مستقل: `sura-admin.html`. آن را در یک سرویس **HTTPS** ثابت و کنترل‌شده میزبانی کنید؛ برای بررسی محلی می‌توان موقتاً با HTTP روی `127.0.0.1` اجرا کرد.
- کد واقعی سرویس فعال و نسخه‌بندی‌شده: `https://github.com/hossean787-blip/Saba-Android/blob/main/supabase/functions/sura-admin-api/index.ts`؛ سرویس Supabase با نام `sura-admin-api` و `verify_jwt=true` در پروژه مجاز فعال است.
- فایل `backend/sura-admin-api.ts` پیاده‌سازی TypeScript متناظر برای بررسی و بایگانی است؛ **نسخه دقیق مستقر در GitHub لینک بالا** ذخیره شده و مبنای بازیابی است.
- مهاجرت دقیق بایگانی‌شده در GitHub: `supabase/migrations/20261109_sura_admin_atomic_credit_adjustments_audit.sql`؛ یک بار روی پروژه اجرا شده است. آن را دوباره بدون بررسی تاریخچه مهاجرت اجرا نکنید.
- دیتابیس میزبان فقط سامانه SURA است: Supabase پروژه `fiiitzfbdjzpmepzjsjw`. هیچ دیتابیس پروژه دیگری استفاده نشده.
- ورود با ایمیل و رمز Supabase Auth و کاربر تأییدشده و نقش ثبت‌شده در `sura_admin_roles`. کلید `service_role` هرگز در HTML، اپ یا مخزن قرار نگیرد. کلید عمومی Publishable برای مرورگر مجاز است.

## قابلیت‌ها

داشبورد و آمار فروش، جدول کیف‌پول کاربران و مؤدیان، انتقال اعتبار، اصلاح/هدیه اتمیک با شماره درخواست و ثبت دلیل، دفتر ممیزی، تراکنش‌ها، گزارش گردش مبالغ وصول‌شده، صادرات CSV و در دسترس بودن کتابخانه XLSX صادرات اکسل، قیمت پایه صورتحساب، نمایش موبایل و میزکار، تغییر تم.

**سطوح دسترسی**: مدیر ارشد اختیار قیمت و اعتبار؛ ویرایشگر دسترسی مشاهده و برخی خروجی‌ها؛ ناظر مشاهده. تغییر اعتبار از سمت سرور هم فقط برای مدیر ارشد پذیرفته می‌شود.

**نکته مالی**: مبالغ برحسب ریال و قیمت فعلی هر اعتبار ۱۰۰٬۰۰۰ ریال است. اطلاعات تفکیک مالیات بر ارزش افزوده/خالص در سفارش موجود نیست؛ گزارش از محاسبه نرخ مالیات فرضی خودداری می‌کند. برای بیش از ۱۰۰۰ سفارش باید خروجی صفحه‌بندی‌شده یا سروری ساخته شود؛ صفحه هشدار محدودیت را نشان می‌دهد.

## آزمون و شواهد

- مرورگر Chromium+Playwright: ورود نمایشی، مجوز مدیر، اصلاح اعتبار، انتقال، قیمت‌گذاری، گزارش CSV، منوی موبایل، تغییر تم، پیمایش — موفق با API شبیه‌سازی‌شده، نه حساب واقعی.
- JavaScript: بررسی نحو Node.js موفق. TypeScript: بررسی نحوی با تعریف Deno و TypeScript موفق.
- پایگاه داده واقعی: اجرای مهاجرت موفق، بررسی محدود بودن اجرای RPC به service_role، آزمون داخل تراکنش با اجرای موفق، عدم‌اجرای دوباره و تشخیص مغایرت موجودی؛ داده آزمون بازگردانده و جدول ممیزی صفر رکورد باقی ماند.
- سرویس واقعی: Supabase Edge Function `sura-admin-api` نسخه ۳ ACTIVE.
