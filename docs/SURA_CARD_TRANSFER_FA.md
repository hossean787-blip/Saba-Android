# پرداخت دستی کارت‌به‌کارت — سورا
- فروش پیش‌فرض بسته است؛ شماره کارت و دارنده در جدول خصوصی sura_card_config فقط پس از تأیید مالک تنظیم می‌شود. هر سفارش مبلغ و کارت مقصد مستقل ثبت می‌کند.
- ثبت تصویر JPEG حداکثر ۵۰۰ کیلوبایت و شماره پیگیری و تاریخ؛ تنها مدیرکل می‌تواند رسید را ببیند و بعد از تطبیق مبلغ و شماره مرجع واقعی گردش حساب، تأیید یا رد کند. شارژ اتمی و جلوگیری از تکرار با قیود یکتا.
- پشتیبانی از اشتراک در تسویه؛ قیمت و فروش اشتراک تا تکمیل اتصال مصرف و تعیین قیمت مسدود است.
- UI هر دو اپ و Edge Function اضافه شده‌اند؛ تست CI، نصب، کنترل تراکنش واقعی و سیاست فروشگاه باقی مانده‌اند. شماره کارت، رسید بانکی و اطلاعات محرمانه در Git ذخیره نمی‌شوند.
