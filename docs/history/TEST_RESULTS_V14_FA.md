# گزارش آزمون نسخه ۱۴ صبا

## آزمون‌هایی که واقعاً اجرا شدند

اسکریپت `tools/run-domain-smoke-tests.sh` با کامپایلر `kotlinc` و JVM محیط اجرا شد.

**نتیجه: ۲۲ موفق، صفر ناموفق.**

موارد پوشش‌داده‌شده:
- محاسبه مبلغ خالص، مالیات و مبلغ نهایی
- گرد کردن مالیات با HALF_UP
- ورودی خالی، شرح خالی، تعداد صفر، قیمت/تخفیف منفی، تخفیف بیش از مبلغ ردیف و نرخ مالیات نامعتبر
- جلوگیری از سرریز ضرب و جمع سهمیه
- قواعد مجوز سالانه آزاد، اشتراک ثابت‌تعداد نامعتبر و مجوز تعدادی صفر
- مرز شروع و پایان اعتبار مجوز
- انتقال سهمیه، انتقال بیش از موجودی، انتقال صفر و مصرف سهمیه شرکت انتخاب‌شده

## محدودیت مهم

این‌ها آزمون‌های منطق دامنه‌اند و فایل‌های اصلی `InvoiceCalculator.kt`، `QuotaRules.kt` و `LicensePolicy.kt` را کامپایل می‌کنند. `InvoiceLine.kt` در مسیر آزمون یک مدل سبک مستقل است تا تست‌ها بدون Android/Room اجرا شوند.

## بررسی ساخت کامل اندروید

در محیط حاضر:
- Java قابل اجرا است.
- `kotlinc` موجود است.
- فرمان `gradle` موجود نیست.
- `ANDROID_HOME` تنظیم نشده و Android SDK شناخته‌شده‌ای پیدا نشد.
- پروژه از Android Gradle Plugin 8.7.3، Kotlin 2.0.21 و `compileSdk = 35` استفاده می‌کند.

در نتیجه، `testDebugUnitTest`، پردازش Room/KSP، کامپایل Compose و `assembleDebug` در این اجرا ممکن نشدند. هیچ ادعایی مبنی بر ساخته‌شدن APK یا موفقیت تست دیتابیس مطرح نیست.

## مواردی که هنوز باید با محیط اندروید آزمایش شوند

1. کامپایل کامل پروژه و پردازش annotationهای Room/KSP.
2. تست دیتابیس واقعی برای انتقال تکراری با همان `operationId` و درخواست متفاوت.
3. تراکنش‌های هم‌زمان انتقال و نهایی‌سازی.
4. ساخت APK و نصب روی دستگاه/شبیه‌ساز.
