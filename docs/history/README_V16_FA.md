# صبا — بسته بازبینی نسخه ۱۶

این بسته نسخه آغازین اپ مدیریت فاکتور اندروید را به همراه وضعیت پروژه و نتیجه آزمون دامنه ارائه می‌کند.

## آزمون سریع دامنه
با Kotlin compiler و Java نصب‌شده:

```bash
bash tools/run-domain-smoke-tests.sh
```

نتیجه اجرای انجام‌شده در 2026-10-26: **۲۲ موفق، صفر ناموفق**.

## وضعیت واقعی
- رابط Compose و ذخیره‌سازی محلی Room در سطح نمونه وجود دارند.
- محاسبات فاکتور و قواعد سهمیه/مجوز آزمون‌های مستقل دامنه دارند.
- اتصال رسمی سامانه مؤدیان آماده نیست و برنامه ادعای ارسال واقعی نمی‌کند.
- APK در این نوبت ساخته نشده؛ کامپایل اندروید و اجرای روی دستگاه تأیید نشده‌اند.
- فایل GitHub Actions موجود است اما در GitHub آنلاین اجرا و تأیید نشده است.

جزئیات: `PROJECT_STATUS.md` و `TEST_RESULTS_V16_FA.md`.


## تغییرات بسته بعدی
در بازبینی بعدی، صفحه تنظیمات از نوار اصلی در دسترس است و کنترل اندازه نوشته‌ها (85٪ تا 135٪) و نمایش روشن وضعیت اتصال سامانه مؤدیان افزوده شده است. تنظیم اندازه نوشته فعلاً فقط در طول اجرای جاری حفظ می‌شود.
