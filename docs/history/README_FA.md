# فاکتور صبا — بسته ادغام‌شده نسخه ۲۱

این بسته از سورس اندروید و اسناد اتصال مالیاتی نسخه ۲۰، همراه با سورس پاک‌سازی‌شده وب نسخه ۱۹ تشکیل شده است.

- **اندروید:** `app/` و فایل‌های Gradle و `.github/workflows/`؛ هنوز APK تولید و تأیید نشده است.
- **وب آفلاین:** `Saba_Offline_App.html`، کد قابل نگهداری در `src/` و ابزار ساخت `tools/build.py`.
- **آزمون:** `tools/run-domain-smoke-tests.sh`، `tools/check-tax-preflight-v20.sh` و `tests/regression.cjs` (آزمون مرورگر نیازمند Playwright است).
- **اتصال مؤدیان:** صرفاً اعتبارسنجی مقدماتی و طراحی درگاه؛ ارسال واقعی فعال نیست.
- **مرجع مالیتور:** مستندات و فهرست صفحات، نه کپی کد یا اطلاعات خصوصی سایت.

## ساخت نمونه وب

```sh
python tools/build.py
node --check src/app.js
```

## محدودیت‌های مهم

این بسته یک پروژه توسعه‌ای ادغام‌شده است، **نه نسخه تجاری نهایی یا APK نصب‌شدنی**. آزمون‌های مرورگر، ساخت اندروید، ارتباط مالیاتی و آزمون دستگاه واقعی تا زمان اجرای موفقشان نباید PASS تلقی شوند. داده‌های وب در مرورگر به‌صورت محلی و بدون رمزگذاری ذخیره می‌شوند.

جزئیات شواهد ادغام در `MERGE_REPORT_V21_FA.md` آمده است.
