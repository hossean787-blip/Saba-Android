# راهنمای ساخت ابری صبا — نسخه ۱۵

این نسخه یک workflow برای GitHub Actions اضافه می‌کند تا روی runner لینوکسی با Java 17، تست‌های منطق مستقل، تست‌های واحد اندروید و ساخت APK اجرا شوند.

## فایل افزوده‌شده

`.github/workflows/android-build.yml`

## نکته مهم

این workflow در این محیط اجرا نشده است؛ فقط فایل پیکربندی به پروژه اضافه شده. برای اجرای آن باید پروژه به یک مخزن GitHub ارسال شود و از بخش Actions، اجرای workflow فعال باشد. پس از اجرا، گزارش تست و APK در بخش Artifacts ظاهر می‌شود، مشروط به موفقیت build.

## فرمان‌های اصلی در runner

- `bash tools/run-domain-smoke-tests.sh`
- `gradle testDebugUnitTest --no-daemon`
- `gradle assembleDebug --no-daemon`

## محدودیت‌های باقی‌مانده

- تا پیش از اجرای workflow، خطاهای احتمالی کامپایل Compose/KSP/Room تأیید نشده‌اند.
- آزمون دیتابیس هم‌زمان و اجرای روی دستگاه هنوز لازم است.
- اتصال واقعی به سامانه مؤدیان و مجوز تجاری سمت سرور هنوز پیاده‌سازی نشده‌اند.
