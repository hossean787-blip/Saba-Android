# راهنمای محیط ساخت صبا برای لپ‌تاپ Windows 7 x64

## تشخیص فعلی
پروژه در وضعیت فعلی از Android Gradle Plugin 8.7.3، Kotlin 2.0.21، JVM target 17 و compileSdk 35 استفاده می‌کند. لپ‌تاپ ثبت‌شده Windows 7 x64 و Java 8 دارد و Gradle/Android SDK در آن شناسایی نشده‌اند؛ بنابراین تنظیم فعلی روی این دستگاه آماده ساخت نیست.

## توصیه امن
برای ساخت نسخه فعلی، از یک رایانه یا محیط ساخت جداگانه با سیستم‌عامل پشتیبانی‌شده، JDK 17، Android SDK Platform 35، Android Build Tools سازگار و Gradle موردنیاز Android Gradle Plugin استفاده کنید. سپس در پوشه پروژه این فرمان‌ها اجرا شوند:

```text
gradle --version
gradle testDebugUnitTest
gradle assembleDebug
```

این فرمان‌ها فقط پس از نصب Gradle/Wrapper و SDK اجرا می‌شوند؛ در حال حاضر نتیجه‌ای از اجرای آن‌ها ادعا نمی‌شود.

## چرا نصب ساده روی Windows 7 پیشنهاد نمی‌شود؟
- Java 8 فعلی با JVM target 17 پروژه سازگار نیست.
- Android Gradle Plugin 8.x به JDK 17 نیاز دارد.
- ارتقای JDK و ابزارهای جدید Android روی Windows 7 راهکار قابل اتکا و پشتیبانی‌شده‌ای نیست.
- تنزل کل پروژه به ابزارهای قدیمی ممکن است مستلزم تغییر نسخه Kotlin، Compose، Room، SDK و کد برنامه باشد و به‌صورت خودکار امن نیست.

## قبل از ساخت APK
1. نسخه پشتیبان از پوشه پروژه تهیه کنید.
2. از محیطی با JDK 17 و Android SDK سازگار استفاده کنید.
3. ابتدا `testDebugUnitTest` را اجرا کنید و خطاها را رفع کنید.
4. سپس `assembleDebug` را اجرا کنید.
5. APK را روی دستگاه آزمایشی نصب و ثبت/ویرایش فاکتور، انتقال سهمیه، نهایی‌سازی و رفتار پس از خطا را آزمایش کنید.

## وضعیت این نسخه
این فایل راهنمای تشخیص و مسیر پیشنهادی است؛ نصب ابزار روی لپ‌تاپ کاربر انجام نشده و APK تولید نشده است.
