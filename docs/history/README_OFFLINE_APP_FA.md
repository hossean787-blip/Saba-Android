# برنامه آفلاین صبا

فایل `Saba_Offline_App.html` را با مرورگر باز کنید. برای استفاده از امکانات، ابتدا شرکت ثبت کنید؛ سپس مشتری بسازید، در بخش سهمیه مقدار آزمایشی اضافه کنید و به شرکت تخصیص دهید. بعد می‌توانید پیش‌نویس فاکتور ثبت و آن را به‌صورت محلی نهایی کنید.

## محدودیت‌های مهم
- این یک نمونه وب آفلاین است، نه APK اندروید.
- داده‌ها در فضای ذخیره‌سازی مرورگر همان دستگاه نگهداری می‌شوند؛ پاک‌کردن داده‌های مرورگر ممکن است آنها را حذف کند. از پشتیبان JSON استفاده کنید.
- سهمیه خرید و تخصیص در این نسخه آزمایشی است؛ پرداخت یا خرید واقعی انجام نمی‌شود.
- «نهایی‌سازی محلی» فقط وضعیت فاکتور را تغییر می‌دهد و یک سهمیه محلی مصرف می‌کند؛ به سامانه مؤدیان ارسال نمی‌کند.
- برای نسخه تجاری باید APK کامپایل و تست شود، احراز هویت و مجوزها در سرور پیاده‌سازی شوند، و اتصال رسمی سامانه مؤدیان با دسترسی مجاز تست شود.
