# سیاست دائمی به‌روزرسانی سورا

این سند فقط مربوط به پروژه اندرویدی SURA در مخزن Saba-Android است.

1. تمام نسخه‌های انتشار و به‌روزرسانی بعدی باید با **همان کلید امضای دائمی انتشار سورا** امضا شوند؛ تغییر یا بازتولید کلید بدون طرح مهاجرت و تأیید صریح مالک ممنوع است.
2. شناسه نصب Android (`applicationId`) باید ثابت بماند. `versionCode` هر نسخه جدید باید از نسخه منتشرشده قبلی بزرگ‌تر باشد.
3. مسیر پیش‌فرض انتشار، **نصب به‌روزرسانی روی نسخه موجود، بدون حذف برنامه** و با حفظ داده‌های محلی، مؤدیان و کلیدهای خصوصی است.
4. پیش از تحویل، اجرای `apksigner verify` و ثبت اثر انگشت گواهی، بررسی `applicationId` و `versionCode` و آزمون ارتقا از نسخه قبلی به نسخه جدید الزامی است. موفقیت ساخت APK به‌تنهایی به معنی موفقیت ارتقا نیست.
5. کلید خصوصی انتشار و گذرواژه‌ها نباید وارد مخزن، لاگ‌ها یا مستندات شوند. فقط از Secrets مجاز GitHub Actions استفاده شود.
6. کلیدهای خصوصی مؤدیان که به Android Keystore وابسته‌اند ممکن است با حذف برنامه، پاک‌کردن داده‌ها یا تعویض دستگاه غیرقابل بازیابی شوند؛ هیچ دستور حذف برنامه نباید بدون بررسی و رضایت کاربر داده شود.
7. نسخه Debug و Release ممکن است امضای متفاوتی داشته باشند؛ نصب روی هم بدون سازگاری امضا نباید تضمین شود.
8. وضعیت فعلی: اجرای موفق ساخت APK امضاشده در GitHub Actions: `41145944196`. این موفقیت، **سازگاری نصب روی نسخه قبلی دستگاه کاربر را اثبات نمی‌کند**.
