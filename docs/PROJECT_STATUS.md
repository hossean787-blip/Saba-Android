# وضعیت پروژه فاکتور صبا

## مبنای محلی
- آخرین بسته ادغام‌شده محلی: Saba_Invoice_Merged_v21.zip
- سورس اندروید و نمونه وب آفلاین در بسته محلی وجود دارند.
- آخرین گزارش محلی: ۲۲ آزمون منطق دامنه موفق؛ آزمون Android و مرورگر کامل نیست.
- SDK جاوا سامانه مؤدیان نسخه 0.0.58 برای بررسی اولیه استفاده شده؛ اتصال عملیاتی هنوز فعال نیست.
- نمونه PDF صورتحساب مالیتور فقط مرجع ساختار چاپ و کنترل محاسبات است و داده‌های واقعی آن نباید در مخزن عمومی قرار گیرند.

## وضعیت انتشار
این مخزن هنوز حاوی تمام فایل‌های بسته محلی نسخه ۲۱ نیست. APK قابل نصب و ارسال واقعی تأیید نشده است.

## گام‌های ضروری
۱. انتقال کامل و بازبینی سورس اندروید و وب از بسته محلی.
۲. بررسی مجوز و امنیت فایل‌ها پیش از ثبت.
۳. اجرای Gradle build و تست روی Android.
۴. تکمیل و تست اتصال سامانه مؤدیان با داده‌های آزمایشی.
