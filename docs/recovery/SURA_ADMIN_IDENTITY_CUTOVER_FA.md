## نتیجه انتقال
چهار Edge Function فعال با شناسه جدید. migration موفق؛ یک مدیرکل، نقش قبلی null، دو رکورد ممیزی، قید designated_superadmin با UUID جدید. چهار تابع حساس برای UUID قبلی forbidden دادند. آزمون ورود واقعی با دستگاه کاربر باقی مانده. نسخه نصب‌شده مدیر با نشانی کامل مستقل وارد می‌شود؛ نام نمایشی اصلی نیازمند نسخه بعدی است. هیچ رمز یا حساب عادی و هیچ تراکنش مالی تغییر نکرده است.
