# صبا ۱۹ — نسخهٔ پاک‌سازی‌شده

این بسته، بازبینی و اصلاح همان نمونهٔ وب آفلاین نسخهٔ ۱۹ است. فایل اصلی ارسالی دست‌نخورده باقی مانده است.

## اجرا

فایل `Saba_Offline_App.html` را در یک مرورگر جدید باز کنید. برای کار عادی به Node، نصب وابستگی، سرور یا اینترنت نیاز ندارد. برای آزمون در محیط‌هایی که بازکردن مستقیم فایل را محدود می‌کنند، در پوشهٔ برنامه `python -m http.server 8000 --bind 127.0.0.1` را اجرا و نشانی `http://127.0.0.1:8000/Saba_Offline_App.html` را باز کنید.

ابتدا شرکت، سپس مشتری ثبت کنید. سهمیهٔ آزمایشی اضافه و به شرکت تخصیص دهید؛ پیش‌نویس فاکتور بسازید و در صورت نیاز محلی نهایی کنید. هیچ پرداخت یا ارسال مالیاتی واقعی انجام نمی‌شود.

## ساختار مرتب‌شده

- `src/app.js`: منطق برنامه و اعتبارسنجی داده‌ها.
- `src/styles.css`: ظاهر و قواعد واکنش‌گرا.
- `src/index.template.html`: قالب فارسی و راست‌به‌چپ.
- `tools/build.py`: تولید مجدد HTML مستقل با کتابخانهٔ استاندارد Python.
- `tests/regression.cjs`: آزمون مرورگر با Playwright و Chromium.
- `docs/CODE_REVIEW_FA.md`: یافته‌ها، اصلاحات و محدودیت‌ها.
- `docs/history/`: تمام ۲۱ فایل مستندات و فهرست قبلی، بدون تغییر محتوا؛ گزارش‌های تاریخی، وضعیت فعلی این بسته را اثبات نمی‌کنند.

برای تغییر کد، فایل‌های `src` را ویرایش و سپس اجرا کنید:

```sh
python tools/build.py
node --check src/app.js
```

برای آزمون توسعه، Node.js، بستهٔ `playwright` نسخهٔ 1.62.1 و Chromium نیاز است. با `npm install` وابستگی آزمون نصب می‌شود؛ سپس `npm test` اجرا کنید. مسیر Chromium به‌طور پیش‌فرض `/usr/bin/chromium` است و با متغیر `SABA_CHROMIUM` قابل تغییر است. نصب وابستگی فقط برای توسعه و آزمون است.

## داده‌های موجود

کلید ذخیره‌سازی قبلی `saba_offline_v1` حفظ شده است. پشتیبان معتبر نسخهٔ ۱۹ قابل بازیابی است. جابه‌جایی فایل یا تغییر نشانی/پروفایل مرورگر ممکن است فضای ذخیره‌سازی متفاوتی ایجاد کند؛ پیش از انتقال، از نسخهٔ قبلی خروجی JSON بگیرید.

بازیابی معتبر، پس از تأیید کاربر داده‌های فعلی را جایگزین می‌کند. پشتیبان ناسازگار رد می‌شود؛ این برنامه مبالغ یا روابط مالی ناسازگار را خودکار حدس نمی‌زند. اگر دادهٔ موجود خراب باشد، ثبت جدید مسدود می‌شود تا پشتیبان معتبر بازیابی یا داده‌ها با تأیید صریح پاک شوند. داده‌های مرورگر رمزگذاری نشده‌اند؛ پشتیبان را در محل مناسب نگه دارید.

## حدود این نسخه

این خروجی APK یا نرم‌افزار کامل حسابداری نیست. دفتر کل، اسناد دوطرفه، سال مالی، حسابداری انبار، تراز و سودوزیان هنوز پیاده‌سازی نشده‌اند. پاک‌سازی کد جایگزین توسعه و آزمون این هسته نیست. فرم فاکتور همچنان تک‌ردیفی است و اتصال رسمی سامانهٔ مؤدیان وجود ندارد.
