# سورا — گیت فروش مستقیم (نسخه ۰٫۴۱٫۰، ۱۴۰۵/۰۸/۲۳)
- تغییرات: بازیابی سفارش در انتظار از سرور پس از بستن برنامه؛ جلوگیری از پرداخت تازه هنگام اختلال استعلام؛ غیرفعال‌کردن اشتراک ماهانه و فرم فاکتور رسمی خرید اعتبار تا تکمیل واقعی؛ حذف پلن نمایشی.
- تست‌ها: آزمون pure rules در Node و typecheck Deno؛ آزمون parse شناسه سفارش در Robolectric؛ CI و امضای Release باید برای Commit جدید گزارش شود.
- سرور: Edge Function در مسیر /pending برای کاربر احرازشده فقط آخرین سفارش requested با authority معتبر را بدون تراکنش جدید برمی‌گرداند؛ اعتباردهی صرفاً پس از verify سمت سرور.
- versionCode استاندارد ۴۱ و بستهٔ بانک کامل ۴۲، بالاتر از ۳۹ و ۴۰؛ APK باید با گواهی انتشار قبلی امضا شود.
- هنوز تایید نشده: پرداخت واقعی و تطبیق اعتبارات، صدور فاکتور رسمی خرید اعتبار، ارسال/پذیرش واقعی سامانه مؤدیان، نصب ارتقایی روی گوشی مالک، بازپرداخت و شرایط فروش.
- فروش در بازار: تنها پس از جایگزینی پرداخت زرین‌پال با پرداخت درون‌برنامه‌ای بازار در بسته مخصوص آن فروشگاه.
- هیچ اطلاعات محرمانه، کلید خصوصی یا داده مشتری در مخزن قرار نگرفته است.
