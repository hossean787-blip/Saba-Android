# SURA SQLCipher migration laboratory — 2026-11-26
Branch only, no production DB access, no distribution APK change. Candidate community dependency 4.16.0 is androidTest-only; verify compatibility, notices, current advisories and size before selecting production version. The device test exports a populated synthetic Room DB into a separate encrypted file, preserves schema version, tests reopen, financial row values, foreign keys and wrong key. It does NOT implement production key persistence, atomic cutover, or removal of old plaintext.

Production gates: generate per-account random DB key, wrap with Android Keystore AES-GCM and account-bound AAD; durable metadata; never generate a replacement key for an existing encrypted DB; block rather than silently fall back. Migrate only with no open writers; checkpoint WAL; create candidate in same private filesystem, verify full logical row counts and canonical digests, all tables/triggers/indexes and Room schema; fsync candidate and durable phase marker; repeat interrupted migration without losing source; use atomic cutover and recovery state; preserve encrypted rollback before removing plaintext plus sidecars, and do not claim flash secure erasure. Include saved-identifier and legacy DBs in scope; media/history separate. Test disk-full, process kill each phase, wrong key, lost Keystore, two accounts, API23/29/36 and signed upgrade with real app data (synthetic only). No production switch until independently verified. References: https://www.zetetic.net/sqlcipher/sqlcipher-api/ and https://www.zetetic.net/sqlcipher/sqlcipher-for-android-migration/ .

2026-11-26 follow-up: the laboratory now uses a durable, per-account 256-bit random passphrase wrapped with Android Keystore AES-GCM and account-bound AAD. Tests verify reopening, separation, tampered envelope, missing Keystore, and fail-closed behavior with existing ciphertext. The helper is deliberately androidTest-only; do not activate production cutover until full-row/schema digest, crash and disk-full tests pass. No production data is affected.
