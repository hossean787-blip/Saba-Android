# دروازه ایمنی پرداخت عمومی سورا — ۱۴ نوامبر ۲۰۲۶

مسیر خرید عمومی به‌صورت **fail-closed** است. تا زمانی که هر سه شرط برقرار نباشد، هیچ سفارش تازه‌ای از `/create` نباید ایجاد شود:
1. `ZARINPAL_MERCHANT_ID` معتبر روی سرور
2. `SURA_PAYMENT_EGRESS_URL` با HTTPS و `SURA_PAYMENT_EGRESS_SECRET` (سرور دارای IP ثابت و ثبت در پنل زرین‌پال)
3. `SURA_PAYMENTS_LIVE_ENABLED=true` فقط پس از آزمون مجاز پرداخت و بازگشت

تابع پیش‌فاکتور `sura-credit-quote` نیز همان شرایط را برای `payment_enabled` در UI بررسی می‌کند. استعلام و reconcile سفارش‌های قدیمی، مستقل از امکان ایجاد سفارش جدید باقی می‌ماند. آزمون واقعی و مستند، شرط فعال‌سازی است.

**هنوز انجام‌نشده:** تهیه VPS دارای IP ثابت، HTTPS، secretهای سرور، allowlist IP زرین‌پال، تراکنش واقعی کوچک و تسویه اتمی. هیچ خرید یا هزینه‌ای بدون تأیید مالک مجاز نیست.
