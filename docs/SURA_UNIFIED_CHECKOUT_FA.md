# خرید یکپارچه سورا
انتخاب پلن (تکی، اشتراک ماهانه، هدیه) فقط یک بار در صفحه خرید؛ استعلام قیمت از API کارت‌به‌کارت؛ ادامه خرید، انتخاب روش و ثبت سفارش، سپس رسید. زرین‌پال از خرید جدید حذف شده، کد و مسیر استعلام سفارش‌های قبلی حفظ شده است. یک سفارش فعال مقدم بر خرید جدید است؛ قیمت و تعداد به انتخاب جاری مقید می‌شوند. اشتراک تا فعال‌سازی مجاز سرور قابل خرید نیست. قیمت جدید یا پاسخ نامشخص باعث استعلام مجدد می‌شود؛ هیچ سفارش یا تراکنش واقعی در این تغییر ایجاد نشده است. آزمون CI باید بررسی شود.
