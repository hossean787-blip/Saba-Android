# طبقه‌بندی خطاها
کدهای عمومی ثابت و پیام فارسی بر اساس خطای سرور، HTTP یا نوع استثنا. ثبت‌نام تکراری 409؛ رمز ضعیف و تأیید ایمیل جدا. در مسیر مالی نتیجه نامشخص به معنی شکست قطعی نیست؛ همان شناسه پیگیری شود. تشخیص DNS، TLS، timeout، فایل، مجوز، فضای ذخیره، قیود SQLite و خرابی پایگاه داده. پوشش این مرحله: احراز هویت، خرید/انتقال/هدیه، کارت‌به‌کارت، مؤدیان، کلیدها، صورتحساب، مشتری، شناسه‌ها، پشتیبانی و پیام‌های عمومی پنل مدیر. مسیرهای قدیمی خاص همچنان نیازمند ممیزی کامل و آزمون دستگاه‌اند؛ همه خطاهای سرویس مالیاتی واقعی هنوز قابل تشخیص نیستند. هیچ پرداخت یا تغییر اعتبار ایجاد نشد. نتیجه CI و استقرار تابع جداگانه بررسی شود.
