# فاکتور صبا | Saba Invoice

اپلیکیشن اندرویدی صدور و مدیریت صورتحساب الکترونیکی، با هدف اتصال مستقیم به سامانه مؤدیان ایران.

## وضعیت واقعی

- بسته ادغام‌شده محلی: نسخه ۲۱ (سورس اولیه Android و نمونه وب آفلاین)
- اصلاحات یکپارچه بررسی‌شده: ۱۰۶ آزمون JVM/Robolectric موفق، همراه ساخت محلی APK و Lint بدون خطا؛ شواهد در `docs/build/CI_STATUS_FA.md` ثبت شده است.
- ساخت مستقل: با JDK 17، Android SDK و Gradle Wrapper موجود در مخزن انجام می‌شود؛ به سرویس GitHub Actions نیاز ندارد.
- GitHub Actions: به علت خطای پرداخت یا سقف مصرف حساب، پیش از شروع runner مسدود است؛ موفقیت محلی به معنی موفقیت CI گیت‌هاب نیست.
- اتصال واقعی به سامانه مؤدیان: هنوز تکمیل و آزموده نشده
- بررسی مرجع مالیتور: برای طراحی مستقل امکانات و گردش‌کارها؛ بدون کپی کد اختصاصی

> این نسخه برای ثبت محلی و آزمایش است؛ نصب و ارتقای واقعی روی گوشی و ارسال رسمی مؤدیان هنوز تأیید نشده‌اند.

## ساخت و آزمون Android

```sh
bash scripts/build-offline-ci.sh
```

راهنمای پیش‌نیازها و رفع مانع حساب: [وضعیت CI](docs/build/CI_STATUS_FA.md).

## الزامات امنیتی

کلید خصوصی، رمز عبور، توکن، اطلاعات نشست و مشخصات واقعی مؤدیان نباید در مخزن قرار گیرند.
