# فاکتور صبا | Saba Invoice

اپلیکیشن اندرویدی صدور و مدیریت صورتحساب الکترونیکی، با هدف اتصال مستقیم به سامانه مؤدیان ایران.

## وضعیت واقعی

- بسته ادغام‌شده محلی: نسخه ۲۱ (سورس اولیه Android و نمونه وب آفلاین)
- آزمون‌های مستقل منطق دامنه: ۲۲ مورد موفق در آخرین گزارش محلی
- ساخت APK: هنوز تأیید نشده
- اتصال واقعی به سامانه مؤدیان: هنوز تکمیل و آزموده نشده
- بررسی مرجع مالیتور: برای طراحی مستقل امکانات و گردش‌کارها؛ بدون کپی کد اختصاصی

> توجه: این مخزن در حال راه‌اندازی است. درج این README به معنی بارگذاری همه فایل‌های نسخه ۲۱ نیست.

## الزامات امنیتی

کلید خصوصی، رمز عبور، توکن، اطلاعات نشست و مشخصات واقعی مؤدیان نباید در مخزن قرار گیرند.
