# صورتحساب سورا | SURA — Android

اپلیکیشن مستقل ثبت و مدیریت صورتحساب، با آماده‌سازی اطلاعات موردنیاز سامانه مؤدیان.

## وضعیت کد در شاخه main — ۱۴۰۵/۰۸/۱۷ (۲۰۲۶-۱۱-۰۸)

- نسخه معمول برنامه: `0.25.0` با `versionCode=25`؛ نسخه اختیاری دارای بانک داخلی کامل: `0.26.0` با `versionCode=26`.
- فرم چندردیفی فاکتور، پیش‌نویس و نهایی‌سازی، ثبت اطلاعات مالیاتی، نمایش PDF و مسیر درخواست ارسال رسمی در کد وجود دارند.
- ساخت APK امضاشده و آزمون‌های شبیه‌ساز برای نسخه قبلی **گزارش شده‌اند**؛ پس از هر تغییر جدید، موفقیت ساخت/آزمون باید دوباره ثبت شود.
- درخواست رسمی ارسال صورتحساب، بدون احراز هویت معتبر مؤدی و آزمون پذیرش واقعی، **تأییدشده محسوب نمی‌شود**؛ نتیجه شبیه‌سازی، رسید رسمی مالیاتی نیست.
- کلید خصوصی متعلق به مؤدی باید فقط در دستگاه/مخزن امن مجاز نگهداری شود؛ هرگز در GitHub یا APK قرارداده نشود.
- ارتباط HTTPS مالیاتی، نشانی رسمی `tp.tax.gov.ir` را با محدودیت پورت و پاسخ ۸ مگابایتی کنترل می‌کند. آزمون‌های مستقل امنیتی آن در `SecureMoadianGatewayTest.kt` هستند.

## آزمون و ساخت

به JDK 17 کامل و Android SDK platform 35 و build-tools 34.0.0 نیاز است:

```sh
bash scripts/build-offline-ci.sh
```

این دستور آزمون‌های JVM، Lint و **APK Debug آزمایشی** می‌سازد، نه فایل قابل انتشار امضاشده.

ساخت Release با امضای معتبر تنها در محیط مورداعتماد و با چهار متغیر `SURA_RELEASE_STORE_FILE`، `SURA_RELEASE_STORE_PASSWORD`، `SURA_RELEASE_KEY_ALIAS` و `SURA_RELEASE_KEY_PASSWORD` انجام می‌شود. از ذخیره اطلاعات امضا در مخزن خودداری کنید.

آزمون ارتقای نصب بدون حذف نسخه قبلی در `scripts/verify-signed-upgrade.sh` تعریف شده است؛ اجرای این آزمون، حفظ داده واقعی کاربر را به‌تنهایی اثبات نمی‌کند.

## موانع تأیید تولید

۱. اجرای کامل ساخت/آزمون نسخه جدید در محیط دارای Android SDK و بررسی خطاهای CI پس از آخرین Commit.
۲. آزمون ارتقا و حفظ اطلاعات بر روی دستگاه هدف با نسخه امضاشده و کلید امضای ثابت.
۳. آزمون یکپارچه احراز هویت، اعتبارسنجی کلید خصوصی و شناسه یکتا، ارسال، استعلام و رسید **واقعی** سامانه مؤدیان با حساب مجاز و داده آزمون مجاز.
۴. رفع هرگونه محدودیت حساب GitHub Actions، اگر همچنان از طرف GitHub گزارش شود؛ جزئیات قدیمی در `docs/build/CI_STATUS_FA.md` برای سابقه حفظ شده‌اند.

هیچ‌یک از گام‌های فوق را صرفاً براساس ساخت Debug یا شبیه‌ساز موفق اعلام نکنید. پروژه مستقل است و نباید فایل، کلید یا داده پروژه‌های دیگر را در آن وارد کرد.
