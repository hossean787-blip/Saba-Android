# گزارش کنترل کیفیت سورا مدیر RC1 — ۲۰ آبان ۱۴۰۵

**دامنه:** اپ مدیریت مستقل، سرور واقعی مشترک، حفظ اپ مشتری، بدون اجرای عملیات مالی روی داده تولیدی.

## تکمیل و آزموده‌شده

- API اختصاصی `sura-manager-api` روی پروژه `fiiitzfbdjzpmepzjsjw` با تأیید JWT و نقش به نسخه ۲ ارتقا یافت.
- Migration غیرمخرب `sura_manager_v1_audit_roles_price_and_summary` با موفقیت اعمال شد.
- بررسی SQL: کاربران `authenticated` امکان اجرای RPC تغییر قیمت یا نقش را ندارند؛ `service_role` مجاز است.
- آزمون تراکنشی SQL داخل زیرتراکنش با بازگردانی: گزارش تجمیعی، ممنوعیت حذف نقش خود مدیر، اصلاح قیمت، اجرای مجدد همان درخواست و کنترل قیمت تغییرکرده؛ بدون حفظ هیچ تغییر مالی آزمایشی.
- آزمون محلی backend: ۱۷ سناریو مجوز، صفحه‌بندی، ایمیل مقصد، قیمت، سلامت، نقش و جست‌وجو: PASS.
- آزمون مرورگر با داده شبیه‌سازی‌شده: ورود، داشبورد، فهرست کاربران، جزئیات کاربر، تغییر نقش، ممیزی، وضعیت سرویس، قیمت، اصلاح اعتبار، انتقال، پرداخت‌ها، CSV، XLSX، تم و موبایل: PASS.
- کنترل منابع اپ: WebView دارای محدودیت دامنه/مبدأ، CSP، منع TLS ناامن و فایل‌های ناشناس؛ کلید محرمانه در APK/سورس وجود ندارد؛ شناسه برنامه مستقل است.

## آزمون‌های باقی‌مانده برای عرضه تجاری

- نصب و اجرای این **نسخه RC1** روی شبیه‌سازهای اندروید ۱۰ و ۱۵ (در GitHub Actions پس از Commit).
- ساخت Release امضاشده و بررسی گواهی/شناسه و نصب روی دستگاه هدف (در GitHub Actions پس از Commit).
- ورود با حساب واقعی مدیر در اپ نصب‌شده و تأیید نقش از سرور؛ تست endpointهای جدید با JWT واقعی.
- آزمون مجاز یک عملیات واقعیِ کنترل‌شده با ثبت دفتر ممیزی و بازیابی/بازگشت، بدون اثر روی حساب مشتری.
- آزمون رگرسیون ارسال رسمی صورتحساب در اپ مشتری (خارج از سورا مدیر).
- فعال‌سازی Supabase leaked-password protection در تنظیمات Auth.

## هشدارهای درست‌نمایی

- «سفارش موفق» به معنای پذیرش صورتحساب در سامانه مؤدیان نیست.
- مالیات و خالص فروش محاسبه نمی‌شوند چون اسکیمای سفارش نرخ مالیات ندارد.
- گزارش CSV/XLSX محدود به آخرین ۱۰۰۰ سفارش است؛ مجموع کارت‌ها از تمام رکوردها محاسبه می‌شوند.
- نقش‌های جدید/قیمت هیچ‌یک در پایگاه داده واقعی برای تست دائمی تغییر داده نشده‌اند.
- امضای Debug با ساخت‌های قدیمی پایدار نیست؛ از Release امضاشده برای نصب آینده استفاده شود.

## بازیابی

- سورس اپ و پیکربندی Build در `sura-admin-android/` روی main.
- کد سرویس در `sura-admin-android/backend/sura-manager-api.ts` و نسخه در Supabase Edge Functions.
- Migration ثبت‌شده در `sura-admin-android/backend/sura_manager_v1.sql` و تاریخچه پروژه Supabase.
- نسخه پیشین اپ مستقل از بسته `SURA-Manager-Android-v0.1.0-beta-SOURCE.zip` قابل بازیابی است؛ تغییرات اپ مشتری نداشته‌ایم.
